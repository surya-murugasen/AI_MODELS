# Daily Report — 2026-08-25

## Summary

Built out a new **Predictive AI** page for the AI Text-to-Image Generator frontend, then iterated on it across several rounds of fixes and feature additions based on feedback.

## What was done

1. **Added the Predictive AI page**
   - New sidebar entry and route (`frontend/src/components/views/PredictiveAIView.tsx`).
   - Heuristic accuracy-scoring engine (`frontend/src/lib/predictive.ts`) since the app has no database or user feedback loop — accuracy is estimated from model, steps, guidance scale, resolution, and prompt detail.
   - Dashboard: stat tiles (overall accuracy, total generations, high-accuracy count, avg generation time, top model), a next-image accuracy prediction card, a recommended-settings card, charts (accuracy by model, accuracy by resolution), and a filterable/exportable generations table.
   - Custom lightweight SVG chart components (`frontend/src/components/charts.tsx`) — no new chart dependency added.

2. **Reworked accuracy into a 4-category breakdown**
   - Replaced the generic settings-factor breakdown with **Prompt Match / Visual Quality / Composition / Artifact-Free**, with **Overall Accuracy** as their average — shown in the prediction card and available per generation via a hover tooltip.

3. **Made every metric strictly data-driven**
   - Removed all zero-history heuristic fallbacks. With no real generations, every stat, the prediction card, and the recommendation card show **"No data available"** instead of a computed guess — no prediction or recommendation is ever shown without real history behind it.

4. **Added and then fixed the "Image Accuracy Over Time" chart**
   - Built a richer trend chart: real daily accuracy points, a 7-day moving average, and a linear-regression trend projection (only shown once there's enough real day-level history).
   - Fixed a bug where multiple generations from the same session collapsed into a single chart point (calendar-day bucketing was too coarse for a database-less, single-session app) — every real generation now gets its own point.
   - Fixed axis-label duplication/clipping: label precision now adapts to the real time span of the data (seconds/minutes/date-only), and edge labels no longer overflow the chart.

5. **Added a "Prediction vs Actual Result" comparison card**
   - Predictions are now captured *at generation time* (before the result is known) and stored per generation, so they can be honestly compared to the real outcome afterward.
   - Card shows: Predicted Accuracy → Generated Image → Actual Accuracy, plus Prediction Error and Prediction Accuracy, with a selector to review any past generation. Shows "No data available" for generations made before any history existed to predict from (e.g. the very first one).

## Verification

Each change was verified with a headless browser (light/dark mode, empty/sparse/rich data states) using temporary seeded data that was removed afterward. Typecheck, lint, and production build were run clean after every change.
